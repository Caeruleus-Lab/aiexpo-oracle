สี่อาการที่เจอบ่อย

  • /ego-browser ไม่ขึ้น → อยู่ใน Cowork? สลับเป็น Code แล้วรีสตาร์ต Claude
  • ไม่มี Bypass permissions → Settings → Claude Code → Allow bypass permissions mode
  • skill โหลดแต่ ego(lite) ไม่เปิด → สิทธิ์ยังไม่ใช่ Bypass เริ่ม session ใหม่
  • เห็น [ego-browser:notice] → ego-browser upgrade แล้ว ego-browser skill อีกรอบ

snapshot ก่อน แล้วค่อยกด
