## 1. เตรียมมา

- โน้ตบุ๊กที่ติดตั้ง **Claude Code** และล็อกอินแล้ว (แนะนำ Claude Pro; บัญชีฟรีก็เข้าร่วมได้)
- ใช้ Codex หรือ Antigravity แทนได้ ถ้าติดตั้งไว้แล้ว
- ไม่มีโน้ตบุ๊ก: ดูบนจอ แล้วทำตามบนกระดาษแผ่นนี้ได้
- ทำการบ้านก่อนวันงานได้ยิ่งดี (ข้อ 4) จะได้มี Oracle ของตัวเองตั้งแต่ต้นคลาส

## 2. ลงมือ 1 — วงจรความจำ (พิมพ์ทีละบรรทัด)

```text
/recap
```

```text
ช่วยทำงานข้อแรกในหน้าสมุดของฉัน: <งานย่อย>
```

```text
/rrr
```

แล้ว **ปิดหน้าต่าง → เปิดใหม่ →** พิมพ์ `/recap` อีกครั้ง: มันยังจำได้ เพราะจดไว้ในไฟล์ของคุณ

## 3. ลงมือ 2 — จากหนึ่งตัว เป็นทีม

```text
จ้างผู้ช่วย 3 ตัว ทำงานย่อย 3 ข้อที่ฉันติ๊ก "ทีม AI" ไว้ ให้ทำพร้อมกัน แล้วรวมผลเป็นฉบับเดียว บอกด้วยว่าแต่ละตัวทำอะไร
```

สายกระดาษ: วาดว่าใครส่งอะไรให้ใคร

## 4. การบ้าน → e-Certificate (ส่งภายในวันงาน ศุกร์ 6 พ.ย.)

1. ติดตั้ง Claude Code (หรือ Codex / Antigravity) แล้วพิมพ์ `/awaken --fast` ตั้งชื่อ Oracle ของคุณ
2. ทำงานจริงหนึ่งชิ้น แล้ว `/rrr`
3. ส่ง **ลิงก์ repo** หรือ **รูปหน้าสมุด** (ติดตั้งไม่ได้ก็นับ)
4. ชื่อที่ส่ง = ชื่อบน e-Certificate สะกดให้ถูก
